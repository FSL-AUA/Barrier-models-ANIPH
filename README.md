# ANIPH Machine Learning Models

This repository contains the machine learning (ML) workflow developed in the ANIPH project for predicting water vapour permeability (WVP) of PHA polymers.

The folder includes the following files:

Original dataset (ANIPH_mclPHA_WVTR_database_v0.4.0_with_calc_1.xlsx)

Jupyter notebook containing data preprocessing, model training and evaluation (PHA_WVP_regression_LM.ipynb)

Note: Several ML models were investigated and compared during the development of the predictive models. The notebook presents the two best-performing approaches: Random Forest (RF) and Gaussian Process Regression (GPR).
